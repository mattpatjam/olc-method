# The OLC Method — Client Engagement Framework

*Version: 2.0 | Updated: 2026-06-18*

---

## What This Is

The master index for OLC's client delivery system. Every engagement follows this framework. The phases are non-negotiable. The tools and tactics inside each phase evolve.

OLC is an outsourced sales partner. We design the offer, build the demand, and close the deals. The developer runs their project; we run their sales engine.

---

## Phase Overview

| Phase | Name | Benefit | Detail |
|---|---|---|---|
| 0 | **Audit** | *Clarity* | Free diagnostic — show them exactly what it's costing them | [phase-0-audit.md](phase-0-audit.md) |
| 1 | **Offer** | *Foundation* | Brand foundation + offer design + ICP + playbook + full sales infrastructure | [phase-1-offer.md](phase-1-offer.md) |
| 2 | **Leads** | *Demand* | Lead machine live — ads, outreach automation, qualified pipeline | [phase-2-leads.md](phase-2-leads.md) |
| 3 | **Close** | *Conversion* | OLC operates the full sales function and closes deals | [phase-3-close.md](phase-3-close.md) |
| 4 | **Scale** | *Growth* | System learns from every campaign and deal — next cycle performs better | [phase-4-scale.md](phase-4-scale.md) |

**Phase 0 is the hook.** Free. No number in client presentations. How prospects become clients.

**Once Phase 2 launches, Phases 2, 3, and 4 run in parallel** — not as a linear handoff.

---

## Phase Dependencies

```
Audit (0)  → defines scope and surfaces gaps for Phase 1
Phase 1    → determines everything in Phase 2: market, messaging, channels, qualification criteria
Phase 2    → feeds qualified pipeline into Phase 3
Phase 3    → generates call data, objection patterns, conversion rates → feeds Phase 4
Phase 4    → loops back into Phase 2 (better targeting) and Phase 3 (tighter playbook)
```
