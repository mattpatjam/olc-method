## Traffic Strategy

OLC currently runs on warm/hot traffic only — the BE network, referrals, Matthieu's personal reputation. No cold traffic strategy. No owned audience.

| Type | Current state | Next step |
|---|---|---|
| Control (paid) | None | Define a test budget + channel (LinkedIn most likely for B2B developer outreach) |
| Earned | Strong (word of mouth, Matthieu's reputation) | Systematize referrals, capture in CRM |
| Owned | None | Start an email list for developer audience. Use case study as the bait. |

This is the "L" in OLC. Without an owned audience strategy, OLC can't scale past Matthieu's personal network.

## Seven Phases — Developer Client Audit

| Phase | Typical developer situation | Fix |
|---|---|---|
| Traffic temp | Running cold ads to a core offer page | Add a frame bridge (warm up first) |
| Frame bridge | None — ad goes straight to units | Lead with a hook about ROI or project vision |
| Qualify subscribers | No list — all traffic goes to unit page | Add a lead magnet (ROI calculator, project masterclass) |
| Qualify buyers | No immediate offer after opt-in | Add a low-ticket or discovery offer right after opt-in |
| Hyperactive buyers | Not tracked | Tag anyone who inquires immediately and escalate to priority follow-up |
| Age and ascend | Manual WhatsApp follow-ups, no system | Build a follow-up sequence; use the attractive character to build trust |
| Change environment | Everything by WhatsApp | Move serious buyers to in-person site visit or video call |

## Funnel-Builder Skill — Build Sequence

When the `funnel-builder` skill is built, this is the sequence it follows:

1. VLMS — write the mission statement first (who, what, how)
2. Secret Formula — answer the 4 questions (dream customer, where they are, bait, result)
3. Value Ladder — map all current and planned offers, identify gaps
4. Funnel Hacking — research phase: 6+ competitor funnels, map their hook/story/offer at each step
5. Seven Phases audit — diagnose where the current funnel (or lack of one) breaks down
6. Pick funnel type — match the right funnel structure to the offer and audience temperature
7. Hook/Story/Offer — write the copy for each page using the framework
8. Attractive character — define or refine the persona that will run through every message
9. Follow-up — design the Soap Opera Sequence or broadcast calendar
10. Traffic — define the traffic sources and how to convert each type to owned audience

Framework definitions for each step → `.claude/knowledge/dotcom-secrets-reference.md`

**Repeat-partner note (build this in from day one, don't retrofit later):** mirrors `offer-builder`'s Phase 0. If the developer is a returning partner, Steps 1-2 (Dream Customer, Secret Formula) should pull forward the prior project's funnel/campaign data instead of starting blank, only the genuinely new parts (new inventory, new buyer segment) need fresh answers.
